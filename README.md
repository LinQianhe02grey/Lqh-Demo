## Featured Project — Cardwin

**2D 横版动作 / 卡牌子弹构筑 Demo**  
技术：Unity / C# / AI 辅助开发

- **核心战斗机制**：将卡牌转化为 8 发有序弹夹，玩家能够提前获知后续牌序，并在“当前牌如何使用、何时主动换弹、是否为后续关键牌调整节奏”之间持续做取舍，使即时操作与短期资源规划同时参与战斗。
- **构筑与战斗节奏**：以 Damage / Block / Heal / Focus 形成输出、防御、回复与爆发准备四类基础效果；不同牌序直接改变一轮弹夹中的攻防节奏，让构筑结果能够在实际战斗过程中被感知，而不是只停留在战前配置。
- **遭遇与 Boss 设计**：以普通战斗 → 清场 → Boss 作为体验递进，并通过距离、冷却与技能重复控制 Boss 的出招选择，使玩家在贴近、拉距、观察前摇与寻找输出窗口之间形成持续对抗。
