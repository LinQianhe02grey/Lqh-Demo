## Featured Project — Cardwin

**2D 横版动作 / 卡牌子弹构筑 Demo**  
技术：Unity / C# / AI 辅助开发

- **卡牌即子弹**：设计 8 卡有序弹夹，卡牌顺序直接决定后续攻击 / 自用效果；结合后续牌序预览、左右键分流与重装窗口，把弹夹配置和出牌时机变成实时战斗中的核心决策。
- **数据驱动卡牌体系**：以 ScriptableObject 配置 Damage / Block / Heal / Focus 等效果，并将卡牌数据、运行时弹夹、库存与预览 UI 分离，支持快速扩展和验证不同卡牌组合。
- **完整遭遇流程**：从普通房清敌、传送门到 BossRoom，搭建可持续扩展的 Boss 战框架；Boss 根据距离、冷却、权重与重复惩罚选择技能，并拆分为独立动作 / 技能模块。
