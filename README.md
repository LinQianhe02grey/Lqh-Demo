## Featured Project — Cardwin

**2D 横版动作 / 卡牌子弹构筑 Demo**  
技术：Unity / C# / AI 辅助开发

核心设计：
- 设计“**卡牌即子弹**”的实时战斗机制：卡牌装入 8 发弹夹形成攻击序列。
- 战斗中展示最近 3 发弹药预览，支持左键发射、右键自用与换弹。
- 设计并实现 Damage / Block / Heal / Focus 等基础效果。
- 已完成移动、跳跃、二段跳、无敌冲刺、碰撞受击、死亡状态与敌人交互等基础战斗闭环。
- 持续进行战斗手感、敌人行为与系统结构迭代。
