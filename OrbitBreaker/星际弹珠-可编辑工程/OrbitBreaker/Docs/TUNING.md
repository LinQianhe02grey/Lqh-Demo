# T18 调参入口（当前）

Unity 顶部 **Tools → Orbit Breaker → 战斗参数编辑器**。修改后点“保存参数”，再 Play；Ctrl+Z 可撤销。运行中窗口禁用编辑/保存，避免把临时试验写回资产。

- 基础与资源页：沿用 OrbitBreakerCombatConfig 的8项，敌人血量、冲刺上限、掉盾率、冲刺速度/冷却、吸附时长、刷敌间隔、自由模式积分里程碑。
- 速度与Boss页：OrbitBreakerEncounterConfig 的8项，伤害/无敌起速12、最高速24、起速伤害24、最高速伤害80、绕转加速时间2秒、Boss血量2400、移动1.8、攻击间隔4秒。
- 两组均直接修改场景引用的配置资产，不复制一份运行规则。图鉴读取这些资产。原targetScore现在是自由模式的进度里程碑，不再导致胜利；战斗模式只由Boss死亡结算。

实际速度必须**超过**起速，才有伤害和攻击无敌。基础伤害线性随速度增长，再乘连弹倍率。奖励超速可继续增伤。普通移动上限8，不会独立产生伤害。受击后的短恢复保护、洞捕获保护仍保留；黑洞仍扣壳。绕转由6加至当前最高速度，满速发射可以贯穿普通敌人；Boss受伤后始终将玩家反向弹开。

玩法入口是主界面：自由模式 / 战斗模式 / 星际图鉴。左键点击敌人或柱子金环锁定，下一次成功Space向其当前位置发射；空白点击取消，目标死亡或地形被摧毁则清除。E靠近绿柱自动绕转，Space仍需要胶囊次数；E可主动离开。局内Esc清理本局返回主界面；主界面Esc退出（Editor停止Play）。

# 战斗调参（T17）

在 Unity 的 Project 面板选择 `Assets/Config/OrbitBreakerCombatConfig.asset`，Inspector 中会显示中文的“战斗核心参数 · 8项”。建议停止 Play 后修改并保存，再开始游戏。运行模式中的临时修改不作为保存配置。

| 参数 | 当前默认值 | 实际作用 |
|---|---:|---|
| 敌人血量 | 100 | 之后生成的红色敌人和黑色粘稠敌人的初始/最大血量 |
| 冲刺储存上限 | 3 | 可储存1–6次；球上方胶囊槽数量随之变化 |
| 补盾掉落概率 | 0.30 | 击杀敌人时30%概率掉落；0不掉、1必掉；每个道具补1层，最多3层 |
| 基础冲刺速度 | 18 | 普通Space发射的基础速度，奖励和粘稠减速在此基础上计算 |
| 冲刺冷却 | 1秒 | 两次实际冲刺的间隔；冷却不补充次数 |
| 吸附时长 | 7.5秒 | 按E后自动绕转的最大持续时间；到期脱离，不自动消耗冲刺 |
| 刷敌间隔 | 1.2秒 | 每次生成1只；最多12只；每3只中1只粘稠黑敌 |
| 胜利目标积分 | 3000 | 达到阈值时进入Victory，并可按R重开 |

旧版重力7.5、移动加速度20、受击失控0.65秒作为隐藏的序列化兼容数据保留，不占这8个常用调参控件。没有引入第二套战斗配置资产。

## 本轮交互规则

- 小球上方的小胶囊：亮青色代表可用冲刺，暗色代表空槽。每4次有效碰撞或击杀1敌补1次；发射才扣除。
- E检测半径1.6→2.35。自动以360度/秒绕转，约0.6秒实际绕转蓄满；不用鼠标绕圈。鼠标仍决定Space发射方向，Space仍需1次冲刺；无次数时可按E离开或等待时限。
- 奖励洞带金色星标与红色圈：基础600分（再乘连弹倍率），捕获0.65秒后弹出，给予7秒红色加速；冲刺与机关弹射速度×1.35，重复奖励刷新时限，不叠加倍率。基础18的冲刺变24.3，20的弹射变27；红圈/尾迹与倒计时同步，到期恢复。
- 青柱14速普通反弹；紫柱17速并带侧向偏转；金柱21速并略向上偏。球从柱子下侧接触时仍向外弹出，不强行推回柱内。
- 粘稠黑敌有黑色起伏球体和淡紫领域圈，半径3.4；进入后移动加速度和冲刺速度×0.65，多个领域不叠加，离开/敌人死亡立即恢复。吸附绕转仍免敌人干扰；奖励和减速同时存在时乘算。普通机关弹射保持救援力度。
- 补盾为绿色“+”拾取物，存在20秒；满盾时不浪费拾取，最多同时12个，离玩家50单位回收。远处清理敌人不算击杀、不掉落。
- 旋转挡板转速×1.8；摆锤频率1.7→2.8、幅度65→80度，碰撞弹射18→23；浮动板移动/转动更快、摆幅12→22度、弹射17→20。
- 反弹、冲刺、吸附、受击、击杀、奖励、补盾各有程序合成的短音效；音量0.22，反弹音限频避免密集叠加。

保留玩家始终居中、无固定边界/底部弹板、三层护壳、敌人穿障和攻击期间无敌。Windows构建T11仍暂缓。
